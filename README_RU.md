# Русификация Balatro GBA

Ветка `ru-translation` на базе коммита `fc5767c` проекта GBALATRO/balatro-gba.
Шрифт расширен до 224 символов (CP1251), UTF-8-декодирование для байтов >=0x80 в libtonc отключено,
строки собираются с `-fexec-charset=CP1251`. Подписи, нарисованные в PNG, перерисованы скриптами из `ru-tools/`.
Неофициальный проект, не связан с LocalThunk и Playstack. Ром в репозитории не распространяется.
